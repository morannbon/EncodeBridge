# EncodeBridge v1.0.3

**最低対応TvAIr：v1.2.14以上**

**推奨TvAIr：v1.3.0**

## v1.0.3 の更新内容

- **変換アプリの取り違え防止**：NVEncCの実行ファイルをFFmpegとして登録するなどの不一致を検出します。登録時・プロファイル保存時には修正が必要な項目を赤文字で示します。既存の不一致設定も一覧に警告します。変換開始前にも照合して誤った引数での実行を防ぎます。設定不一致で失敗した履歴はプロファイルの修正後に手動で再実行できます。
- **保存先の設定漏れ防止**：保存先の方法を明示的に選択できるようにしました。指定フォルダーが空白のまま登録される問題も防ぎます。以前の設定で保存方法を確認できないプロファイルには赤文字で確認を求めます。
- **入力不足の表示**：保存先・実行ファイル・有効にした変換後バッチが未設定の場合は該当項目の直下に赤文字で案内します。正しい設定が揃うまで保存しません。
- **保存後の照合**：保存済みプロファイルをストレージから再読込します。保存先・変換条件・変換後処理を照合してから保存完了を表示します。
- **プロファイル保存の表示改善**：保存結果を該当するプロファイルと一覧下部に明示します。画面更新後も保存済みの項目を判別できます。
- **重複登録の防止**：同じ保存操作の多重送信を防止します。新たに追加操作を開始した場合は同一設定でも別のプロファイルとして登録できます。
- **保存と通知の整合性改善**：設定の保存後にTvAIrへの選択肢通知が失敗した場合も保存済みであることを画面に表示します。

## 製品説明

EncodeBridgeはTvAIrで録画した番組を外部の変換アプリへ引き渡すPluginです。録画結果が確定したあとに登録済みのプロファイルを使用して変換します。録画途中のTSを直接変換しません。

### 予約の種類と自動変換

- 番組表予約・AI-rhythm予約・プログラム予約・今すぐ録画などは自動変換ON時に既定プロファイルを使用します。
- **自動検索予約のみ**：各ルールで「EncodeBridgeを利用」をONにして変換プロファイルを選択した場合に変換します。使用指定のないルールは正常な対象外です。無効なプロファイルを勝手に既定へ切り替えません。
- 手動停止した録画は自動変換しません。変換対象はファイル確定済み・読取可能・1MiB以上であることが必要です。
- 変換失敗時は途中ファイルと元TSを自動削除しません。中断ジョブの自動再開・再実行もしません。

## 動作環境

- Windows / .NET 8
- Visual Studio 2022（ソースからビルドする場合）
- 外部変換アプリは別途導入が必要です。

## インストール方法

1. 配布ZIPを展開します。
2. `EncodeBridge.sln` をVisual Studio 2022で開きます。
3. 使用しているTvAIrに合わせて `Release | x64` または `Release | x86` を選択してソリューションをビルドします。
4. TvAIrを終了します。
5. 生成された `EncodeBridge.dll` をTvAIrのPluginフォルダ直下へコピーします。
6. TvAIrを起動します。
7. Pluginメニューに「EncodeBridge」が表示されることを確認します。

### 生成されるDLL

Release x64の場合:

```text
EncodeBridge\bin\x64\Release\net8.0-windows\EncodeBridge.dll
```

Release x86の場合:

```text
EncodeBridge\bin\x86\Release\net8.0-windows\EncodeBridge.dll
```

ソリューションのビルドでは `TvAIrPlugin.dll` も生成されます。これはビルドに必要な共通コードの出力です。EncodeBridgeのインストール対象は `EncodeBridge.dll` だけです。

### TvAIrへの配置先

`TvAIr.exe` があるフォルダを基準に次の場所へ配置します。

```text
<TvAIr.exeのあるフォルダ>\Plugins\EncodeBridge.dll
```

例:

```text
TvAIr\Plugins\EncodeBridge.dll
```

更新時もTvAIrを終了してから既存の `EncodeBridge.dll` を新しいDLLへ置き換えてください。

設定や履歴などの保存データを削除する必要はありません。

## 対応する変換アプリ

以下の変換アプリに対応しています。

- NVEncC
- QSVEncC
- VCEEncC
- FFmpeg
- HandBrakeCLI
- Amatsukaze
- TMPGEnc Video Mastering Works（Project Creatorを使用する方式。出力テンプレートの設定が必要です）
- その他のコマンドライン変換アプリ（引数を設定して使用）

AviUtl / AviUtl2のGUI自動操作には対応していません。

## 基本的な使い方

### 1. EncodeBridgeを開く

TvAIrのPluginメニューから「EncodeBridge」を開きます。

### 2. 自動変換を設定する

「自動変換」をONにすると録画結果が確定したあとに自動で変換処理へ送られます。

OFFの場合は自動変換しません。

### 3. 変換アプリを選ぶ

「変換アプリ」から使用するアプリを選択します。

### 4. 実行ファイルを指定する

「実行ファイル」の参照ボタンから使用する変換アプリの実行ファイルを指定します。

例:

- `NVEncC64.exe`
- `QSVEncC64.exe`
- `VCEEncC64.exe`
- `ffmpeg.exe`
- `HandBrakeCLI.exe`

変換アプリの種類と実行ファイル名が一致しない場合は保存できません。該当項目に赤文字で原因を表示します。名称から判別できない実行ファイルも組み合わせを確認できないため保存できません。独自CLIを使用する場合は「その他CLI」を選択してください。

### 5. 品質を選ぶ

「品質」から次の3段階を選択できます。

- 高画質設定
- 標準設定
- 少容量設定

各変換アプリに応じた品質設定を使用します。

- NVEncC: QVBR
- QSVEncC: ICQ
- VCEEncC: QVBR
- FFmpeg: CRF
- HandBrakeCLI: RF

### 6. 映像設定を選ぶ

使用する映像コーデックなどを設定します。

設定できる内容は選択した変換アプリによって異なります。

### 7. 出力形式を選ぶ

出力形式を選択します。

主に以下を利用できます。

- MP4
- MKV

入力映像の解像度は原則としてそのまま維持します。

1920×1080の映像は1920×1080のまま出力します。

1440×1080などの放送素材ではアスペクト比情報を考慮して処理します。

### 8. 保存先を指定する

変換後ファイルの保存方法を次の3種類から選択します。

- **指定したフォルダー**：参照ボタンから保存先フォルダーを選択します。フォルダーが未指定の場合は設定を保存できません。
- **元TSと同じ場所**：元の録画TSと同じフォルダーへ出力します。
- **元TSのサブフォルダー**：元の録画TSのフォルダー内に変換用サブフォルダーを作成して出力します。

保存方法の選択が必要です。保存先フォルダーの空欄だけで「元TSと同じ場所」へ自動切替することはありません。

以前の設定で保存方法が確認できないプロファイルは編集画面で保存方法を選び直してください。既存の保存設定は自動で書き換えません。

## 自動変換の流れ

自動変換がONの場合は次の順序で処理します。

1. TvAIrで録画
2. 録画結果確定
3. EncodeBridgeが録画結果を受信
4. 変換待ちへ登録
5. 外部変換アプリを起動
6. 変換処理
7. 出力ファイル確定
8. 完了

録画中のファイルを途中から変換することはありません。

TvAIr側で録画結果が確定したあとに処理を開始します。

## 変換中の動作

EncodeBridgeのウィンドウを閉じても実行中の変換処理は継続します。

ウィンドウ表示中のみ画面表示を定期更新します。

閉じている間は不要な画面更新を行いません。

## 変換後バッチ

変換設定の「変換後バッチ」へWindowsバッチコマンドを直接記述できます。

この機能は上級者向けです。初期状態では無効です。「変換成功後にバッチを実行する」を初めてONにする際は保存前に確認画面を表示します。削除・移動・上書きなどのコマンドを実行できることを案内します。内容と実行結果を自己責任で使用することも確認します。「自己責任を了承します」を選んだ場合だけ設定を保存します。キャンセルした場合はバッチ有効化を保存しません。

この処理は変換結果の確定後だけ実行します。変換に失敗した場合は実行しません。管理者権限へ自動昇格する処理はありません。

バッチには任意のWindowsコマンドを記述できます。ファイルの削除・移動・上書きや外部プログラムの起動も可能です。バッチの記述内容とコマンド自身が生じさせた結果はサポート対象外です。EncodeBridgeによる誤ったパス展開・二重実行・変換失敗時の実行などの実装不具合はサポート対象外には含みません。

利用できる置換文字:

- `{source}` : 元の録画TSファイル
- `{output}` : 変換後の出力ファイル
- `{sourceDir}` : 元TSのフォルダ
- `{outputDir}` : 出力先フォルダ
- `{sourceName}` : 元TSのファイル名
- `{outputName}` : 出力ファイル名

例: 変換成功後に元TSを削除する場合

```bat
del /q {source}
```

例: 元TSを別フォルダへ移動する場合

```bat
move /Y {source} "<移動先フォルダ>"
```

バッチ欄が空の場合や「変換成功後にバッチを実行する」がOFFの場合は元の録画ファイルを削除・移動・名前変更しません。

## 元の録画ファイルについて

EncodeBridge自身は元の録画ファイルを自動で削除・移動・名前変更しません。

「変換後バッチ」の利用許可を行って実行をONにして保存した場合だけユーザーが記述したコマンドに従って処理します。

## 過去版の更新履歴

### v1.0.2 の更新内容

- **自動変換の安定性向上**：録画終了時の取りこぼしや重複変換を防ぎました。分割された録画ファイルにも対応しました。
- **異常終了・再起動時の安全性向上**：設定・履歴・録画ファイルを保護しました。意図しない再実行や上書きも防止しました。
- **変換待機処理の改善**：保存先の容量不足や変換アプリの一時的な問題が起きても安全に待機します。ほかの変換も妨げません。
- **再実行・履歴操作の改善**：再実行・停止・待機中の削除・履歴削除の動作を整理しました。処理結果や待機理由も分かりやすく表示します。
- **スリープ防止の改善**：変換中はスリープを防ぎます。待機中や完了後は不要な電源維持を解除するようにしました。
- **画面表示の改善**：ウィンドウを閉じている間の不要な更新を停止しました。ちらつきも抑えました。

### v1.0.1 の更新内容

- 録画終了後の自動変換を安定化しました。通常予約は既定プロファイルに従います。自動検索予約のみルールごとに「EncodeBridgeを利用」とプロファイルの両方を指定した場合に変換します。
- 録画確定からエンコード完了・変換後処理までのスリープ抑止の引継ぎを改善しました。
- 手動停止した録画は自動変換しないよう修正しました。通常の録画完了後に生成された1MiB以上の対象ファイルを変換します。
- TvAIrの終了・再起動で中断した変換は自動再開しません。元TSや途中ファイルは保持します。
- 複数の変換プロファイル・既定プロファイルの選択・変換後バッチ・変換履歴の個別削除・一括削除に対応しました。
- その他軽微な修正。

### v1.0.0

- 初回公開版。録画後の外部変換アプリ連携を追加しました。

## 注意事項

- 使用する変換アプリは別途用意してください。
- 対応コーデックや利用条件は各変換アプリの仕様に従います。
- GPUエンコードを利用する場合は対応GPUとドライバが必要です。
- 外部変換アプリでエラーが発生した場合は各アプリのログも確認してください。
