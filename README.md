# EncodeBridge v1.0.1

## v1.0.1 の更新内容

- 録画終了後の自動変換を安定化しました。通常予約は既定プロファイルに従い、自動検索予約のみルールごとに「EncodeBridgeを利用」とプロファイルの両方を指定した場合に変換します。
- 録画確定からエンコード完了・変換後処理まで、スリープ抑止の引継ぎを改善しました。
- 手動停止した録画は自動変換しないよう修正しました。通常の録画完了後に生成された1MiB以上の対象ファイルを変換します。
- TvAIrの終了・再起動で中断した変換は自動再開しません。元TSや途中ファイルは保持します。
- 複数の変換プロファイル、既定プロファイルの選択、変換後バッチ、変換履歴の個別削除・一括削除に対応しました。
- その他軽微な修正。

## 製品説明

EncodeBridgeは、TvAIrで録画した番組を外部の変換アプリへ引き渡すPluginです。録画結果が確定したあとに、登録したプロファイルを使用して変換します。録画途中のTSを直接変換しません。

### 予約の種類と自動変換

- 番組表予約、AI-rhythm予約、プログラム予約、今すぐ録画などは、自動変換ON時に既定プロファイルを使用します。
- **自動検索予約のみ**、その自動検索ルールで「EncodeBridgeを利用」をONにし、変換プロファイルも選択する必要があります。どちらかが欠ける場合は変換しません。無効なプロファイルを勝手に既定へ切り替えません。
- 手動停止した録画は自動変換しません。変換対象はファイル確定済み・読取可能・1MiB以上であることが必要です。
- 変換失敗時、途中ファイルと元TSを自動削除しません。中断ジョブの自動再開・再実行もしません。

## 動作環境

- TvAIr v1.2.14（Host/Plugin SDK Contract 1.1.18対応構成で動作確認済み）
- Windows / .NET 8
- Visual Studio 2022（ソースからビルドする場合）
- 外部変換アプリは別途導入が必要です。

## インストール方法

1. 配布ZIPを展開します。
2. `EncodeBridge.sln` をVisual Studio 2022で開きます。
3. 使用しているTvAIrに合わせて `Release | x64` または `Release | x86` を選択してソリューションをビルドします。
4. TvAIrを終了します。
5. 生成された `EncodeBridge.dll` をTvAIrのPluginフォルダ直下へコピーします。
6. TvAIrを起動します。
7. Pluginメニューに「EncodeBridge」が表示されることを確認します。

### 生成されるDLL

Release x64の場合:

```text
EncodeBridge\bin\x64\Release\net8.0-windows\EncodeBridge.dll
```

Release x86の場合:

```text
EncodeBridge\bin\x86\Release\net8.0-windows\EncodeBridge.dll
```

ソリューションのビルドでは `TvAIrPlugin.dll` も生成されますが、これはSDK契約プロジェクトのビルド出力です。EncodeBridgeのインストール対象は `EncodeBridge.dll` だけです。

### TvAIrへの配置先

`TvAIr.exe` があるフォルダを基準に次の場所へ配置します。

```text
<TvAIr.exeのあるフォルダ>\Plugins\EncodeBridge.dll
```

例:

```text
TvAIr\Plugins\EncodeBridge.dll
```

更新時もTvAIrを終了してから既存の `EncodeBridge.dll` を新しいDLLへ置き換えてください。

設定や履歴などの保存データを削除する必要はありません。

## 対応する変換アプリ

以下の変換アプリに対応しています。

- NVEncC
- QSVEncC
- VCEEncC
- FFmpeg
- HandBrakeCLI
- Amatsukaze

AviUtl / AviUtl2のGUI自動操作には対応していません。

## 基本的な使い方

### 1. EncodeBridgeを開く

TvAIrのPluginメニューから「EncodeBridge」を開きます。

### 2. 自動変換を設定する

「自動変換」をONにすると録画結果が確定したあとに自動で変換処理へ送られます。

OFFの場合は自動変換しません。

### 3. 変換アプリを選ぶ

「変換アプリ」から使用するアプリを選択します。

### 4. 実行ファイルを指定する

「実行ファイル」の参照ボタンから使用する変換アプリの実行ファイルを指定します。

例:

- `NVEncC64.exe`
- `QSVEncC64.exe`
- `VCEEncC64.exe`
- `ffmpeg.exe`
- `HandBrakeCLI.exe`

変換アプリを変更した場合は種類の異なる実行ファイルをそのまま引き継ぎません。

### 5. 品質を選ぶ

「品質」から次の3段階を選択できます。

- 高画質設定
- 標準設定
- 少容量設定

各変換アプリに応じた品質設定を使用します。

- NVEncC: QVBR
- QSVEncC: ICQ
- VCEEncC: QVBR
- FFmpeg: CRF
- HandBrakeCLI: RF

### 6. 映像設定を選ぶ

使用する映像コーデックなどを設定します。

設定できる内容は選択した変換アプリによって異なります。

### 7. 出力形式を選ぶ

出力形式を選択します。

主に以下を利用できます。

- MP4
- MKV

入力映像の解像度は原則としてそのまま維持します。

1920×1080の映像は1920×1080のまま出力します。

1440×1080などの放送素材ではアスペクト比情報を考慮して処理します。

### 8. 保存先を指定する

変換後ファイルの保存先を指定します。

保存先を指定しない場合は元の録画ファイルを基準に出力先が決まります。

## 自動変換の流れ

自動変換がONの場合は次の順序で処理します。

1. TvAIrで録画
2. 録画結果確定
3. EncodeBridgeが録画結果を受信
4. 変換待ちへ登録
5. 外部変換アプリを起動
6. 変換処理
7. 出力ファイル確定
8. 完了

録画中のファイルを途中から変換することはありません。

TvAIr側で録画結果が確定したあとに処理を開始します。

## 変換中の動作

EncodeBridgeのウィンドウを閉じても実行中の変換処理は継続します。

ウィンドウ表示中のみ画面表示を定期更新します。

閉じている間は不要な画面更新を行いません。

## 変換後バッチ

変換設定の「変換後バッチ」へWindowsバッチコマンドを直接記述できます。

この機能は上級者向けです。初期状態では無効です。「変換成功後にバッチを実行する」をONにして初めて保存した場合、その場ではまだ保存せず、削除・移動・上書きなどのコマンドを実行できることと、内容・実行結果を自己責任で使用することを確認表示します。「自己責任を了承します」を選んだ場合だけ設定を保存します。キャンセルした場合はバッチ有効化を保存しません。

この処理は変換結果の確定後だけ実行します。変換に失敗した場合は実行しません。管理者権限へ自動昇格する処理はありません。

バッチには任意のWindowsコマンドを記述できるため、ファイルの削除・移動・上書きや外部プログラムの起動が可能です。バッチの記述内容と、そのコマンド自身が生じさせた結果はサポート対象外です。一方、EncodeBridgeによる誤ったパス展開、二重実行、変換失敗時の実行など、EncodeBridge側の実装不具合はこの対象外には含みません。

利用できる置換文字:

- `{source}` : 元の録画TSファイル
- `{output}` : 変換後の出力ファイル
- `{sourceDir}` : 元TSのフォルダ
- `{outputDir}` : 出力先フォルダ
- `{sourceName}` : 元TSのファイル名
- `{outputName}` : 出力ファイル名

例: 変換成功後に元TSを削除する場合

```bat
del /q {source}
```

例: 元TSを別フォルダへ移動する場合

```bat
move /Y {source} "<移動先フォルダ>"
```

バッチ欄が空の場合、または「変換成功後にバッチを実行する」がOFFの場合、EncodeBridgeは元の録画ファイルを削除・移動・名前変更しません。

## 元の録画ファイルについて

EncodeBridge自身は元の録画ファイルを自動で削除・移動・名前変更しません。

「変換後バッチ」の利用許可を行い、実行をONにして保存した場合のみ、ユーザーが記述したコマンドに従って処理します。

## 注意事項

- 使用する変換アプリは別途用意してください。
- 対応コーデックや利用条件は各変換アプリの仕様に従います。
- GPUエンコードを利用する場合は対応GPUとドライバが必要です。
- 外部変換アプリでエラーが発生した場合は各アプリのログも確認してください。
